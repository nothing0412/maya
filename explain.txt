Problem Statement

Implement Min, Max, Sum, and Average operations using Parallel Reduction in C++ using OpenMP.

This program uses parallel programming to calculate:

Sum of all elements
Minimum element
Maximum element
Average of elements

using multiple threads together.
Deep Explanation of the Problem

Normally, when we calculate sum/min/max:

One CPU core works
Elements are processed one by one

This is called Sequential Processing.

But in Parallel Reduction:

Multiple threads work simultaneously
Array is divided among threads
Each thread calculates partial results
OpenMP combines results automatically

This makes execution faster for large data.

Most Important Part → Parallel Reduction
#pragma omp parallel for reduction(+:sum) reduction(min:min) reduction(max:max)

This is OpenMP directive.

It tells compiler:

"Run this loop in parallel using multiple threads."

Understanding Reduction

Reduction combines results from multiple threads safely.

Without reduction:

Threads may overwrite shared variables
Wrong output occurs
Called Race Condition

Reduction avoids this.

Sum Reduction
reduction(+:sum)

Meaning:

Each thread creates private copy of sum
Performs addition locally
Final sums are combined using +

Example:

Thread 1:

sum = 10

Thread 2:

sum = 20

Final:

30
Minimum Reduction
reduction(min:min)

Each thread finds local minimum.

OpenMP combines all local minimums.

Maximum Reduction
reduction(max:max)

Each thread finds local maximum.

OpenMP combines them.

How Parallel Execution Happens

Suppose:

Array = [1,2,3,4,5,6,7,8]

4 threads work:

Thread	Elements	Partial Sum
T1	1,2	3
T2	3,4	7
T3	5,6	11
T4	7,8	15

Final:

3+7+11+15 = 36

This is called Parallel Reduction.
