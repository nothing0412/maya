Old Fixed Array
int arr[100];
Problem:


Size fixed to 100


Cannot store more than 100 elements


Wastes memory if user enters small size



New Dynamic Vector
vector<int> arr(n);
Meaning:


Create vector of size n


Size decided at runtime


Memory allocated dynamically


If user enters:
5
then vector size becomes 5.
If user enters:
1000
then vector size becomes 1000.

Because vector supports dynamic memory allocation and flexible size.

Q2. Which header file is needed for vector?

Q3. Is vector part of STL?
Yes.
STL = Standard Template Library.
